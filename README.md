# BeforeAfter

**Interactive before & after photo comparison. Slide to reveal. Share your transformation. Zero watermarks. 100% offline.**

## Features
- Interactive 60fps slider
- Zero watermarks on free tier
- 100% offline — no account, no cloud
- 10 languages: EN, ES, FR, DE, PT, AR, HI, JA, KO, ZH
- RTL support (Arabic)
- Light/dark mode
- Accessibility: VoiceOver, Dynamic Type, Reduce Motion
- Ad-supported free tier + Pro subscription ($1.99/mo)

## Build
```bash
flutter pub get
flutter run
```
